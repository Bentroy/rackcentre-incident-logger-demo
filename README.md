# HSE Incident Logger

A full-stack MERN application developed to streamline workplace incident reporting and management. The system enables employees to report incidents while allowing administrators to monitor, manage, and update reports through a centralized dashboard.

## 🚀 Live Demo

https://rackcentre-incident-logger-demo.vercel.app

## 📂 GitHub Repository

https://github.com/Bentroy/rackcentre-incident-logger-demo

---

## ✨ Features

- User Registration & Login
- JWT Authentication
- Password Hashing with bcrypt
- Role-Based Access Control
- Incident Reporting
- Edit & Delete Incidents
- Search & Filter Incidents
- Admin Dashboard
- Responsive Design

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/Bentroy/rackcentre-incident-logger-demo.git
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```
